After the implementation, the next step was to test the code
verify it's validity and then start the mapping.

\section{Testing methods}

Since wolfram and python implementations used symbolic 
expressions, the main test consisted in comparing the resulting
symbolic values of each element: the effective potential and
the Jacobian matrix. Such comparison was done by hand comparing
both outputs (table \ref{tab:symbolic_comparison}).
